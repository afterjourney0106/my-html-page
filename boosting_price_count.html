IGV 代练 · 定价模型样板

以「升级 Power Leveling」这个 SKU 跑通:商品结构 → 费率卡 → 定价公式 → 实时算价 → 建议价区间 → 喂三方案
游戏:Diablo 4 ｜ 模型形态:base + Σdelta × 三系数 ｜ 平台给默认、卖家可覆盖
一句话: 一个 SKU = 一张费率卡(基础价 + 各计价属性的增量表 + 区服/交付/加急三个系数)。同一张卡:方案二让卖家挂牌算价、方案一/三用它做建议价与兜底价。下面这张「升级」卡可直接点选属性实时算价。

① 商品结构:属性与角色

每个属性只承担一种角色:进价格公式(计价)、只用于匹配/筛选/SEO(匹配)、或决定账号安全档(交付)。这决定了费率卡的复杂度。

② 费率卡:base + 增量表 + 系数

卖家上架只需填 base + 几个 delta,三个系数用平台默认即可开卖(在意的卖家可覆盖)。下面是这张「升级」卡的平台默认值。

③ 定价公式

最终价 = ( base + 区间Δ + 巅峰Δ + 职业Δ ) × 区服系数 × 交付系数 × 加急系数

升级是一次性服务,无"数量"项;按次/按量的品类(Boss、Pit、材料)在括号后再乘 × 数量 即可,结构完全一致。

⑤ 建议价服务:一个输出,喂三方案

建议价服务对每个「SKU + 属性组合」输出区间 + 中位,数据来源按优先级:① 在架卖家费率卡 → ② 历史成交价 → ③ 平台基准卡(冷启动兜底)。

方案一 · 卖家竞价
买家「预算参考」用区间引导;IGV 兜底价 = 中位数(X 分钟无人接则按中位兜底)。
方案二 · 卖家挂牌
新卖家填费率卡时给推荐值降门槛;买家跟卖列表用区间做价格锚。
方案三 · 买家定价
买家自己填价时提示「该任务通常 $X–Y」,防止定太低变僵尸单。
说明: 本样板用于验证定价模型跑得通、卖家填得动、买家看得懂。数值为示例占位,真实 delta / 系数由品类运营与卖家共同标定;啃透这张「升级」卡后,其余 SKU(Boss、Pit、成品号…)照抄同一结构:base + delta 表 + 三系数(按次品类多一个 ×数量)。
