要放弃已填的信息吗？

你已经填了区服和 UID。关掉弹窗这些内容不会保存。

01 / 层级

一层遮罩，两个步骤

第二步复用同一个弹窗容器，用 ← 返回 代替第二层遮罩。✕ 永远只有一个含义：退出整个购买流程。容器宽度不变，高度做过渡，避免切换时"抖一下"。

02 / 返回

返回必须无损

点 ← 回到卖家列表，选中的卖家、数量、已填的表单全部保留。再点 Buy Now 直接看到刚才填的内容。原型里可以来回切换验证。

03 / 关闭

填过就要拦一下

第二步已有输入时，点 ✕ 或点遮罩会先弹二次确认。空表单则直接关闭，不打扰。

04 / 表单

字段跟着卖家走

Direct Top Up 要区服 + UID + 平台，Face to Face 则是另一套字段。所以填写必须排在选卖家之后 —— 两步的顺序不能颠倒。

05 / 转化

UID 记忆是最实在的一笔

登录用户默认带出上次该游戏的区服与 UID，第二步从"填三个字段"降为"确认一眼"。这是整个改造里对转化率影响最直接的细节。

06 / 手机端

bottom sheet，不是小弹窗

切到手机视图看：弹窗贴底、圆角顶、可占 88% 高度，底部 CTA 常驻。安卓返回键应对应"上一步"，两个步骤各 push 一条 history state，不能一按就退出列表页。

07 / 可分享

URL 不能丢

弹窗打开时同步改写地址栏到商品详情 URL（看上方地址栏）。分享出去的链接仍要能直接落到商品内容页，SEO 与站外投放都依赖它。

08 / 备选

也可以把第二步挪进 checkout

弹窗只做"选卖家"，Buy Now 直接进结算页填信息 + 付款。弹窗更轻、表单空间充裕，代价是丢掉弹窗内闭环。手机端这个方案往往更好。

交互原型，非真实交易页面：不联网、不收集任何信息，所有卖家、价格、订单数据均为示意。设备视图切换只改变布局，逻辑一致。快捷键 Esc 关闭弹窗。
