维度一 · 游戏基本调研 — Clash Royale
v1.0 · 2026-07-14 · 基于公开资料，数值项待国际服实测复核

回答三个问题：这是一款什么游戏、它的经济怎么运转、交易需求从哪里长出来。结论先行，四个模块支撑。

需求在哪
交易需求几乎 100% 沉淀在「账号」——CR 无自由交易机制（仅存受限且正在退场的部落内换卡系统），金币、卡牌、表情无法直接变现。账号是唯一的「钱包」，也是唯一的变现载体。
第一品类
账号是结构性刚需：F2P 满级一套卡组要 1–2 年；2025 年约 3000 万回流玩家面临进化 / Hero / 16 级三重版本断代——买号等于买「版本入场券」。
复购引擎
代充按月度赛季 + 季度大版本脉冲复购：Pass Royale / Diamond Pass 每月重置；每次 Hero、进化、传奇发布都拉动一波囤宝石——需求按日历自动再生。
优先级初判
账号 > 代充 > 代练；金币、物品机制上不可做。竞对已验证跑通：Eldorado 账号 8,560 条 listing，PlayerAuctions 年 5,200+ 单买家评价。

玩法详解 决定交易需求的六个核心机制
M-01
养成以年计 · 一切需求的源头
F2P 满级一套卡组需 1–2 年活跃游玩，全卡满级社区戏称「大概 8 年」——有玩家 2018 年入坑至今仅满 15 张卡。买号把「年」压缩成「分钟」。
→ 跳过养成 = 买号的第一触发场景，账号业务的基本盘。
M-02
等级压制 · 中端局的持续性痛苦
卡 10–11 级的玩家频繁匹配满级对手，连败掉杯 150–200；社区共识「只有满级对满级才是纯技术局」。这不是「慢」，是每天都在被虐——付费转化最强的痛点。
→ 「刚好越过压制线」的 KT14–15 中端号 = 走量主力（$25–150 价位带）。

M-04
资产近零流通 · 决定品类宽窄
金币、宝石不可在玩家间转移（宝石只能经 Supercell ID 代充进入指定账号）。唯一的例外是 Trade Token 部落内换卡系统：同稀有度卡换卡的以物易物，需同部落 + 代币 + KT16，冠军卡不可换——且 2025.10 起代币已停止产出，官方客服口径暗示系统将最终移除，正在退场。Discord 上的「卡牌交易」群组即围绕此系统，无法建成稳定 SKU。
→ 金币 / 物品品类不可做；账号做大、代充做补充，是唯一的品类结构。
M-05
稀有资产不可再生 · 收藏溢价的来源
CRL 20 胜表情达成率 < 1/16,000；多个顶级稀有表情在前 1,000 名收藏家中仅 20–62 人持有；5 年 / 10 年徽章、S1 表情、老赛季奖励完全绝版。唯一获取方式 = 买下持有它的账号。
→ 稀有表情是账号定价权重最高的单一变量：单项增值 $200–1,000+，且只会升值。
M-06
赛季节奏 · 需求的日历
每月赛季重置（Pass 购买窗口）+ 季度级大版本（Hero / 进化 / 传奇发布拉动限时囤宝石）。行业观察：每逢新 Hero、进化、强力赛季奖励上线，代充需求即上升——买家意图与「即时到账 + 赛季时点」强绑定。
→ 代充按日历脉冲复购；每次大版本 = 账号估值重写 + 一波换号需求。
FIELD NOTE · 一个真实的购买动线（据社区讨论合成）
玩家老 K 2019 年弃坑，2025 年被 Jynxzi 的直播拉回来。登录第一晚：对面满级卡 + 进化 + Hero，自己 11 级的卡组连掉 200 杯。他去查攻略，得到的数字是——想追平，指定进化一张要肝 3 个赛季，Hero 一个要肝 2–3 个月，一共 9 个；16 级卡还得从头攒。他算了算，这至少是一年半。当晚他开始搜「clash royale account with heroes」。——账号买家不是不爱玩，是不接受被版本抛下。

转化障碍 三道信任坎 · 与行业标准应对
T-01 · 第一大顾虑
找回恐惧
所有竞对都把「原主找回怎么办」放 FAQ 首位。行业标准应对：保险期（Eldorado ≥5 天 / PA 7–30 天）+ 找回即全额退款或补号；配套买家教育：到手立即改邮箱密码、更新恢复信息、开 2FA。IGV 上线需同等售后规则。
T-02
封号恐惧
买卖账号违反 Supercell ToS，存在永封风险且 Supercell 执行较严。竞对话术处理：「verified sellers + 遵循卖家交付指引」，不做绝对安全承诺。内容侧用「如何安全接收账号」类指南承接焦虑。
T-03
货不对板
练度虚标、卡组不合打法。应对：截图 / 视频验号 + 描述不符可退；PA 的折中方案值得借鉴——买家可选「保留账号 + 协商降价」，降低全额退货率。结构化属性字段本身就是防虚标工具。

ToSTerms of Service，服务条款。Supercell ToS 明确禁止账号买卖，构成封号风险（见 T-02）。
2FA两步验证。买家接收账号后的标准安全动作之一（改密 + 更新恢复信息 + 开 2FA）。
Trade Token部落内换卡代币（2018 上线）：同稀有度卡换卡的以物易物，需同部落 + KT16。2025.10 起代币停止产出、系统退场中——不构成可运营的交易品类。
Ultimate ChampionRanked 天梯最高段位。历史赛季达成记录是「竞技履历型」买家看重的账号资产。
APPENDIX 评审 Q&A
Q1在竞品平台和 Discord 群组看到过卡牌交易的内容，确认玩家之间无法进行卡牌交易吗？
看到的是真的——CR 存在 Trade Token 部落内换卡系统（2018 上线），Discord 上的「卡牌交易」群组即围绕它组织换卡。但它不是自由交易：只能同稀有度卡换卡（以物易物），不能换金币 / 宝石，冠军卡不可换，且需同部落 + 代币 + KT16。关键现状：2025.10 起代币已停止产出，官方客服口径暗示系统将最终移除，正在退场。结论不变：无法在其上建立稳定 SKU，金币 / 物品品类仍不可做（详见 M-04）。
Q2「3000 万回流玩家面临进化 / Hero / 16 级三重版本断代」具体指什么？
指 2019–2023 年间弃坑、2025 年回流的玩家，回来后发现游戏多了三套他们完全没有的核心系统：① 进化卡（2023 年年中上线，现共 41 张且每赛季新增，主流卡组标配，F2P 攒指定一张 ≈3 赛季）；② Hero（2025 年底上线，现共 14 个且每赛季新增 1–2 个，F2P 解锁一个 ≈2–3 个月）；③ 16 级（2025.11 等级上限从 15 提至 16，老账号的「满级」瞬间不再是满级）。三者叠加 = 账号全方位落后于当前环境，靠肝追平需一年以上。2025 年恰有约 3,000 万人回流，这批人构成「买号追版本」的集中需求——即买家画像②「版本追平型」。
Q3「月度赛季 + 季度大版本脉冲复购」是什么？Pass Royale / Diamond Pass 价值多少、能获取什么？
「脉冲」指代充需求不是匀速的，而是按日历周期性爆发：月度——每月新赛季 Pass 奖励轨重置清零，想要奖励就得再买，每月一个固定购买窗口；季度——新 Hero / 进化 / 新卡发布时，玩家需限时升级追新，囤宝石需求集中爆发。
Pass 体系为两轨制（2024.10 起取消 Gold Pass）：Free Pass 免费轨，含金币箱、少量宝石等基础奖励；Diamond Pass 唯一付费档，约 $11.99 / 月（各地区 / 商店定价有差异），典型赛季含 225 宝石、赛季限定塔皮 + 表情、2500 普通 / 480 稀有 / 90 史诗 / 7 传奇 / 3 冠军万能卡、金币箱等，部分赛季直送赛季 Hero；另有连续开箱队列、挑战免费重试、金色玩家名等特权。2026.05 更新新增连续购买 Streak 奖励（断月清零）——官方在机制上强化「月月买」。社区对「每月都要买」的价格抱怨，正是第三方折扣代充的需求土壤。
Q4竞技比赛都是单人吗？2v2 没有比赛吗？
天梯、Ranked、20 胜挑战、GT、CRL 等竞技体系全部是 1v1 单人——CR 的竞技主轴就是单挑。2v2 是长期存在的组队休闲模式，原本无正式竞技轨道；2025 年复苏期间官方曾上线 2v2 League 给它一条段位线，但重心仍在娱乐社交。对业务的含义：代练 SKU 几乎全部围绕 1v1，2v2 衍生需求可忽略。
Q5「8 卡组」指一个卡组只有 8 张卡吗？杯数和段位有什么区别？
是——一个卡组即 8 张卡（外加 1 张 2024 年加入的「塔卡」，决定防御塔类型），对局中 8 张循环、手持 4 张。因此练度单位很收敛：「满级一套 meta 卡组」就是账号定价的核心单位。杯数与段位是两套并行体系：
杯数（Trophy）段位（Ranked）
属于天梯 Trophy RoadRanked 竞技模式
性质累积积分，赢加输减，解锁竞技场，基本不重置每月赛季重置，重新打
意义账号的长期资产 / 履历（现上限 14,000）当期实力证明（顶端 Ultimate Champion）
对业务账号定价属性（10K / 12K 杯是筛选标签）代练的月度复购 SKU
Q6表情有什么作用？为什么在报告中反复出现？
表情是对局中发送的小动画（嘲讽 / 互动用），零数值作用，纯社交炫耀。它重要恰恰因为「无用但绝版」：大量表情与成就 / 限时绑定——CRL 20 胜挑战表情（达成率 <1/16,000）、GT 百胜表情、赛季 Pass 限定表情，全部过期不可再得，想要只有一条路：买下拥有它的账号。类比其他品类：相当于 CS 的稀有刀皮、老 WoW 号的绝版坐骑——CR 里唯一的稀缺性硬通货。这就是单个顶级稀有表情能让账号溢价 $200–1,000+、权重超过练度本身的原因（见 M-05）。
Q7Hero 是什么？与普通卡有什么区别？进化卡又是什么？
普通卡进化卡（EVO）Hero
是什么基础兵种 / 法术 / 建筑不是新卡，是现有卡的「超级形态」：解锁后同一张卡在对局中循环若干次触发强化状态（如骑士进化 = 冲锋 + 减伤）独立的新卡类型（2025 年底新增），带主动技能需手动释放，现共 14 个、每赛季持续新增；卡组通常仅可带 1 个（1 进化 + 1 冠军/Hero + 1 万能槽）
怎么获取开箱攒卡 + 金币升级（1–16 级）攒进化碎片解锁，F2P 一张 ≈3 赛季Hero 币解锁升级，F2P 一个 ≈2–3 个月
对账号估值基础盘：满级 / 16 级卡数量强溢价：主流卡组标配最强溢价：持有 2–3 个溢价 30–50%
