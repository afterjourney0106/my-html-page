00 一页速览

三家最本质的差别:B2C 自营货架 vs C2C 卖家竞价

Overgear 与 IGGM 是 B2C——平台自营/统一供给,把服务做成标准化商品货架,买家配置好直接下单、平台定价。Eldorado 是 C2C——平台只提供"配置需求 + 撮合"的框架,由卖家(booster)竞价报价,买家从多个报价里挑,价格由市场决定。

对 iGV 的核心启示先说结论:三家都印证"标准化配置器"是 D4 代练的主流交互;而 Eldorado 证明了 C2C 也能把这套配置器跑通(配置 → 卖家竞价 → 选报价)。iGV 作为 C2C,机会正是把 B2C 那种"好逛好配的标准化货架"和 C2C 的"多卖家竞价"结合起来。

01 三家竞品档案

OvergearB2C 自营overgear.com/games/diablo-4

"In-House Boosters(自有 booster、全程受控)"是其核心卖点,强调专业、可控、快启动。品类做得最全、包装最重营销。

商品结构
品类高度标准化:Leveling(Power/Paragon/Bundle)、Bosses、Dungeons、Items、Materials、Build Services、Build Kits、Bundles(套餐)。每个服务是一个独立商品页 + 配置器。
定价方式
平台统一定价;配置器按目标(等级区间/次数/难度)动态算价(前端 JS 渲染)。Bundle 打包立减(如 Leveling Bundle 省 20%),并有 Starter/Ancestral/Mythic/Torment 四档梯度成品套餐。
下单流程
选服务 → 配置(等级/次数/难度/完成方式)→ 直接下单付款 → 系统按区域/排期派单给 booster → 账户内跟进/聊天。先商品后订单。
递送 / 完成方式
三种:Piloted(上号代打,VPN 保护)、Self-play(组队陪同)、Remote Control(远程控制本机);货币/道具类走组队交易。
自定义
有:"Request custom offer / Create your custom offer"——找不到就找专家定制,约 2 分钟回复(走客服/专家撮合,非结构化配置)。
信任 / 保障
In-house booster、Zero-Ban Protocol(纯手工+VPN)、24/7 客服、按服务标 ETA(如满级 30 分钟);Credential on File 协议。
EldoradoC2C 竞价eldorado.gg/diablo-4-boosting

C2C 撮合平台。核心机制是"买家配置需求 → 卖家竞价 → 买家挑报价并可直接砍价",主打"数百 booster 竞争,价格低至省 40%"。

商品结构
前端仍是标准化配置器,顶部一排服务:Power Leveling、Altars of Lilith、Mythic Prankster、Paragon Leveling、Boss Kills、Custom Request。但商品本身不是卖家预先挂的 SKU,而是买家发起需求后由卖家接。
定价方式
无平台定价,卖家竞价。买家配好需求 → 收到多个卖家报价(含价格+交付时间)→ 可与任一卖家聊天砍价。大单可谈"每单折扣"(如多个 Pit/Boss 单价更低)。
下单流程
7 步:选服务 → 填配置信息 → 发送 Request → 卖家发来多个报价 → 与卖家聊细节 → 选定报价付款、开始 → 全程更新/聊天,完成后卖家标记 Delivered。先需求后订单(反向)。
递送 / 完成方式
配置器内含 Solo / Duo / Stream / Solo queue / Offline mode 等完成方式选项;Nightmare Dungeon 等支持 self-play 陪同或 piloted 代打二选一。
自定义
Custom Request 是独立小类:买家用自然语言描述诉求(如只要解锁 Altars、Waypoints、Renown),等卖家报价。明确限制:Custom Request 只能用于 boosting,不能买账号/道具。
信任 / 保障
TradeShield 托管、卖家资质审核、买家保护与质保、money-back;展示"近 337,879 单 98% 好评"。强调价格由买家掌控(多报价+可议价)。
IGGMB2C 自营iggm.com/diablo-4-boosting

B2C。风格务实、SEO/攻略内容重(站内大量 D4 攻略引流)。配置器规整,主打便宜、安全、快。

商品结构
标准化配置器。D4 分 Gold / Items / Carry Run / Boosting 几大类;Boosting 内含 Power Leveling、Paragon、Boss、副本、材料farming、Build 等;Carry Run 单列。
定价方式
平台统一定价。配置器支持选服务器(Season/Eternal · Soft/Hardcore)+ 起止点区间(start/end 分段选点)+ 选项,并按购买数量给折扣(getDiscountByQuantity)。
下单流程
选服务 → 选服务器/区间/选项 → 加入购物车下单付款 → 客服对接开工。先商品后订单。
递送 / 完成方式
以账号代打为主(客服对接);具体完成方式按服务不同,页面未强前置展示。
自定义
无结构化自定义入口;"找不到就联系 24 小时客服定制"——走客服人工,不在前端做组合配置。
信任 / 保障
booster 多重安全验证、不用违规手段、7×24 客服;主打最低价与安全。内容营销(攻略)构建信任与流量。

03 关键发现

发现 1 标准化"配置器"是 D4 代练的行业标配交互

三家(无论 B2C 还是 C2C)前端都是同一套范式:选服务 → 配等级区间/次数/难度/服务器/完成方式 → 出价/下单。这印证 iGV 做标准化配置器方向正确——这是买家已经被教育好的心智。iGV 已有的"分段选点 + 属性系数"配置器与 IGGM 的"start/end 区间 + 服务器 + 选项 + 按量折扣"高度一致。

发现 2 C2C 的差异化正解:Eldorado 式"配置 + 竞价"

Eldorado 证明 C2C 不必牺牲标准化体验:买家照样在规整配置器里配好需求,只是把"平台定价"换成"多卖家竞价 + 可议价",并用"省 40%"把 C2C 的价格优势讲成卖点。这与 iGV 的 C2C 定位天然契合,是比 B2C 更有说服力的价格叙事。

发现 3 自定义(Custom)两条路线,C2C 更适合做成独立小类

B2C 两家(Overgear/IGGM)的"自定义"都是甩给客服人工定制,因为自营模式难以承接长尾。Eldorado 则把 Custom Request 做成一个独立小类(买家描述 → 卖家接),并明确限定只用于 boosting。这正是 iGV Custom 方向的最佳对标——C2C 天然能把自定义结构化承接,而不是丢给客服。

发现 4 套餐/组合是提客单价的通用手法

Overgear 的 Bundle(省 20% + 四档成品套餐 Starter/Ancestral/Mythic/Torment)、Eldorado 的大单议价、IGGM 的按量折扣——三家都用"打包/量大更便宜"拉高客单价。印证 iGV 做 Leveling Bundle / Boss Bundle 与 Custom 组合需求 的价值,且"组合更省"是买家买账的通用逻辑。

发现 5 完成方式(上号/组队)被前置为关键决策,且强绑信任

Overgear 明确区分 Piloted/Self-play/Remote 并强调 VPN、Zero-Ban;Eldorado 把 Solo/Duo/Stream/Offline 放进配置器。完成方式是买家的核心信任决策点,普遍前置展示并配安全话术——印证 iGV 把"组队/给号"作为独立字段前置、并承载押金/安全表达的做法。

发现 6 递送时间以"参考 ETA"呈现,而非硬承诺

Overgear 标"约 30 分钟"级 ETA 但注明依服务而定;Eldorado 的交付时间由卖家在报价里给出(而非平台统一);IGGM 按服务/客服。三家都不把递送时间当成刚性 SLA——印证 iGV "递送时间先用固定值/参考,不做硬约束"的判断。

04 对 iGV 的启示

定位
竞品矩阵里存在一个空位:做成标准化货架的 C2C。B2C(Overgear/IGGM)有标准化不稀奇;纯 C2C 里只有 Eldorado 把"配置+竞价"跑通。iGV 若把"运营配置的标准化商品 + 多卖家竞价 + 结构化 Custom"三者做扎实,就是这一空位里最完整的形态。
  • 标准化优先、坚持配置器范式:与三家一致,这是买家习惯;iGV 的分段单价 + 属性系数已对齐 IGGM/Overgear 的配置逻辑,继续打磨。
  • 价格叙事学 Eldorado:C2C 的"多卖家竞价、价格更低"是比 B2C 更强的卖点,可作为对外主张(类似"省 X%")。
  • Custom 做成结构化独立小类(对标 Eldorado),而非像 B2C 甩给客服;iGV 的 A(购物车)+ C(对话式)方向比 Eldorado 的纯文本描述更进一步,是差异化机会。
  • 套餐/组合继续做:Bundle + Custom 组合 + "组合更省"的呈现,是三家验证过的提客单价手法。
  • 完成方式前置 + 信任绑定:把"组队/给号"前置展示并配押金/托管话术,与竞品一致且是买家决策关键。
  • 递送时间保持"参考":三家都不做硬 SLA,iGV 固定值/参考的方向稳妥。
一句话总结:三家验证了"标准化配置器 + 套餐 + 完成方式前置 + 参考交付时间"是 D4 代练的成熟范式;真正的差异化空位是——用 C2C 的多卖家竞价承接标准化货架,并把 Custom 做成结构化的组合/自定义小类。这正是 iGV 现有规划的方向,竞品数据整体支持,且给出了可借鉴的具体手法(Eldorado 的竞价叙事与 Custom 小类、Overgear 的 Bundle 分档与完成方式话术)。
