iGD4 代练 Demo前台 · 卖家 · 平台

Diablo 4 代练 · Demo 导览

按角色串起来的可点击原型。顶部切换页面；每个页面内原有的交互都可操作，中英切换在各页面右上角。

买家 · 标准化商品（优先）

1 选品类 · 配置需求升级 / 副本 / Boss / 剧情解锁 / 配 Build，填属性；右侧选递送方式（不影响价格）。
→
2 对比在架卖家点「查看卖家」，同规格卖家按各自费率卡自动算价。
→
3 立即购买 · 结算订单进入「我的订单」，与其他品类订单合并。

买家 · Custom（补充）

1 A 组合需求 / C 描述需求代练页最后一个品类「Custom」。字段顺序：赛季 → 平台 → 组合服务 → 出价 → 组合建议价 → 需求备注 → 期望完成时间 → 有效期。
→
2 发布即付款款项托管；需求进入卖家 Request List。
→
3 我的需求只展示需求信息与状态；未接单可取消（全额退款），已接单点「查看订单」进入我的订单。

卖家

上架（单个上架）三步：基础信息 → 详情与服务范围 → 交易、递送与定价（费率卡、自定义等级段闭合校验、递送时长固定值、库存自填）。
·
Request List 接单接单后该需求从列表消失，进入「我的订单」。
·
我的订单 · 我的在售订单与其他品类合并；递送信息展示方案一 / 二待定（页面顶部可切换）；我的在售可查看商品属性与描述。

平台 · 租户后台

Custom 订单落地下单即正式订单，挂代练自营账号；过风控待接单，接单后卖家三列改写为实际卖家；金额 = $1.00 单位商品 × 数量。页面内可切「方案说明」。
原型数据为占位，决策依据见《D4 代练业务需求文档》。
