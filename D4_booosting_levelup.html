游戏:Diablo 4 ｜ base 形态:分段线性 ｜ 通用公式:最终价 = ( base + Σ增量Δ ) × 系数
这份是升级 SKU。 关键点在 base:等级是线性数值型,base 不是死数,而是按等级分段累加算出来的——尾段单价更高,任意起止都能算。巅峰在这里作加购增量(它在「巅峰 SKU」里才是 base 主体)。

② 费率卡:分段线性 base + 增量 + 系数

卖家只需填分段单价和几个 delta,系数用平台默认即可开卖(可覆盖)。

项取值类型

③ 定价公式

最终价 = ( 分段线性base(起点→终点) + 巅峰Δ + 职业Δ ) × 区服系数 × 交付系数 × 加急系数

巅峰若单独售卖(巅峰 SKU),它就用同样的分段线性当 base;此处它是加购增量。

⑤ 建议价服务:一个输出,喂三方案

对每个「SKU + 属性组合」输出区间 + 中位;数据来源:① 在架卖家费率卡 → ② 历史成交价 → ③ 平台基准卡(冷启动兜底)。

方案一 · 卖家竞价
买家「预算参考」用区间引导;IGV 兜底价 = 中位数(X 分钟无人接则按中位兜底)。
方案二 · 卖家挂牌
新卖家填费率卡时给推荐值降门槛;买家跟卖列表用区间做价格锚。
方案三 · 买家定价
买家自己填价时提示「该任务通常 $X–Y」,防止定太低变僵尸单。
说明: 数值为示例占位,真实由品类运营与卖家标定。其余品类各出单独文件、套用本格式:Boss/副本/装备 = 按次固定(单价×数量);成品号 = 档位固定;陪玩/教学 = 时长线性;Custom = 无可计价属性 → 无费率卡,只走方案一竞价 / 方案三买家定价。
