WoW 正式服代练调研报告

三层结构：玩法与需求 · 代练类目与品类 · 竞品格局与市场验证 —— 面向 IGV.com 业务拓展决策
更新日期 2026-8-4 数据口径：竞品页面快照 · 玩家社区反馈 · Midnight 12.0.7 公开资料核实
总结论

WoW 正式服代练需求由“四条终局线 + 赛季装备轨道”持续制造，市场供给成熟且比 D4 更宽。WoW 是长线 MMORPG：满级 90 只是起点，之后团本、大秘境、PvP 评级、深潜四条终局线并行，每个赛季刷新装备上限、评级与限时奖励。从玩法推导出的 8 类玩家需求，全部已被至少一家竞品在售，其中 Overgear 几乎全覆盖。

WoW 代练 = 9 大品类内容 × 3 个横切维度（交付方式 / 配置加价 / 定价与信任），覆盖升级、团本、大秘境、PvP、深潜、装备、成就、收藏、杂项。三家竞品（智慧谷 · Eldorado · Overgear）卖的内容高度重合，区别在组织与定价方式。比 D4 系统更多、代练面更宽——多出深潜、法师塔、玩家住房、专业、完整 PvP 评级体系等整条线。

与 D4 的关键差异：WoW 的装备与绝大多数坐骑拾取即绑定（BoP），只能以代练形态交付，不能作为道具出售——所以 WoW 是“代练面宽、道具交易窄”，可交易的主要是金币、游戏时间与账号。对 IGV 而言，代练是 WoW 的主战场，金币是可并行的独立交易品类。

MODULE A

第一层：玩法与玩家需求

回答“需求从哪里来”：游戏怎么玩、玩法的每个卡点产生什么需求和痛点。

A-1 游戏玩法：满级之后才是正餐

一句话：WoW 正式服是一款长线 MMORPG。玩家先把角色练到满级 90，然后进入终局：在团本、大秘境、PvP、深潜四条线里刷装备、提装等、冲评级和进度，再用更高的装等去挑战更难的内容。每个赛季（约 4–6 个月）刷新装备上限、评级和限时奖励，旧赛季的进度归零重冲。

练到满级 90→选一条或多条终局线→刷装备 / 碎晶提装等→冲更高难度 / 层数 / 评级→拿坐骑、头衔、幻化 赛季更替：装备上限、评级与限时奖励重置；角色本身保留，账号收藏长期累积
玩法环节内容
练级从 1 级练到满级 90（入门门槛）；配套剧情战役、声望 Renown、天空骑术 Skyriding 等账号进度
团本 Raids多人团队副本，分普通 / 英雄 / 史诗三档难度；按周重置掉落；进度成就 AotC（英雄通关）/ Cutting Edge（史诗末 Boss）只在当季可得

PvP 评级竞技场（2v2 / 3v3 / Solo Shuffle）与评级战场（Blitz / RBG）冲分；2400+ 出角斗士 Gladiator 头衔与坐骑

与 D4 的玩法差异

D4 每赛季角色清零，需求按“从头再练”重演；WoW 角色保留，重置的是装备上限、评级与限时奖励，需求按“赛季目标”重演。另一点：WoW 的终局有四条并行线，玩家往往只擅长其中一两条，其余线上的目标（如团本坐骑、PvP 头衔）天然需要外部帮助。

MODULE B

第二层：代练类目与品类骨架

回答“能做什么”：需求按交付方式归入哪类类目，WoW 代练具体卖哪些品类，SKU 由哪些变量组合而成。

B-1 需求 → 类目：按交付方式分三桶

WoW 与 D4 最大的区别在 B 桶：装备与绝大多数坐骑拾取即绑定，不能作为道具交易，玩家想要它们只能“请人带着打”。所以 WoW 的需求绝大部分落在 A 桶，交易类只剩金币、游戏时间与账号。

A · 纯代练服务（帮你打）

需求 1 升级 · 2 装等 · 3 大秘境 · 4 团本 · 5 PvP · 6 收藏 · 7 杂务

WoW 代练的主体。装备与坐骑虽然是“东西”，但因拾取绑定，只能以代刷 / 带打形态交付（如团本 Loot 分配、Gearing 套餐）。

归属：代练类目，覆盖 9 大品类。
B · 货品交易（直接买到东西）

金币 · 游戏时间 · 账号

金币可在拍卖行买可交易装备与制造装备材料；Eldorado 的 WoW 页即分为 Gold / Accounts / Subscription / Items / Boosting 五个 tab。少量 BoE 装备与 TCG 坐骑可作为道具出售。

归属：独立交易品类，落在 IGV 现有的金币 / 账号交易能力上，与代练可交叉销售。
C · 知识服务（帮你学会）

需求 8 学会打

PvP Coaching、VOD 录像复盘、大秘境教学。卖的是“怎么打”而不是“帮你打”。

归属：代练的延伸类目。
与 D4 对照

代练面更宽，道具交易更窄

D4 的装备 / 成品号压在道具 / 账号交易上；WoW 的同类需求几乎全部回到代练。

含义：WoW 的产品重心是代练 SKU 体系，而不是道具上架。

C-4 核心差异

  1. 覆盖最全最深的是 Overgear：把成就、收藏、装备、深潜、角色杂项都做成整条明码 SKU 线。
  2. Eldorado 参数化最干净：8 个“填空式”配置器覆盖主流需求，长尾走 Custom；不做打包成品档。
  3. 智慧谷靠两个高价钩子：PvP 评级 1800–2400 幻化打包 + “傲天打造”毕业装，升级款（¥1）负责引流。
  4. 陪玩性质不同：西方仍只做工具性（Coaching / 按小时代打 / 陪打），智慧谷独有社交娱乐陪玩。
  5. PvP 交付偏 self-play：三家在 PvP 评级上都更倾向陪打组队，兼顾合规与账号安全。
  6. 定价机制与 D4 一致：智慧谷 / Overgear 固定明码 vs Eldorado 竞价撮合，是三家最底层的分歧。
